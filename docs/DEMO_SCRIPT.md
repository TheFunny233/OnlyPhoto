# 演示脚本

目标：在几分钟内展示 PhotoMaster 的完整主线。含“无密钥演示”与“真实模式”两条路径。

## 准备

```powershell
powershell -ExecutionPolicy Bypass -File scripts/bootstrap.ps1   # 环境 + 迁移 + 演示数据
.tools\run.cmd exec next start -p 3000                            # 或 next dev
```

- 无 AI Key：保持 `AI_MODE=mock`，结果会标注“演示模式”，仅展示结构示例。
- 有 AI Key：`.env.local` 设 `AI_MODE=live` 及对应配置，真实调用后标注“真实调用”。

演示账号（仅 `APP_DEMO_MODE=true`）：`demo.a@photomaster.local` / `demo12345`（用户 A），`demo.b@photomaster.local` / `demo12345`（用户 B）。这是**演示账号**，不是真实用户规模。

## 主线（约 3–5 分钟）

1. **首页**：展示主张、示例图、上传与地图入口、三个真实功能、精选机位。
2. **注册/登录**：创建新账号（或使用演示账号）。
3. **上传**：工作台选择一张照片 → 阅读并勾选“将图片发送到所配置的 AI 服务”的同意 → 上传。
4. **分析**：选择场景与目标 → 开始分析 → 查看总览、“先做这一件事”、四部分（优点/可改进/重拍/修图）、不确定性、来源信息；点击照片上的高亮框定位到对应条目。
5. **编辑**：切换“编辑预览”，调整曝光/对比/饱和/暖冷与裁切 → “对比原图” → 保存方案 → 导出 JPEG/WebP（说明会去除元数据、原图不被覆盖）。
6. **发布机位**：分析页点“发布到机位” → 位置（地图点选 + 精度）→ 样张（可选）→ 拍法 → 公开确认 → 发布 → 跳转机位详情。
7. **发现**：`/explore` 地图与列表联动、筛选、定位、底图失败降级。
8. **社区（双用户）**：用用户 B 登录同一机位 → 点赞、收藏、评论 → 刷新仍在；用户 A 刷新看到互动计数。
9. **个人空间**：`/me` 查看照片、分析、发布、收藏、最近编辑。

## 说明要点（对观众）

- 演示机位均为**演示数据**，配图非此地实拍，不要据此导航或进入受限区域。
- 无密钥时不会假装对任意新图给出针对性结论。
- 真实模式失败会**明确报错并提供重试**，不会悄悄回退到演示。

## 无网络降级

- 地图底图不可用时显示“地图暂不可用”，列表与位置文字仍可浏览。
- 主要页面与示例图片已保存在项目内，离线可演示。
