# OnlyPhoto 产品说明

## 一句话定义

OnlyPhoto 是一款面向普通手机摄影用户的 AI 摄影指导与机位社区网站。用户上传照片后，获得围绕拍摄意图的优点、问题、重拍建议和修图建议；可以在原图上查看简单修改的真实预览，也能通过地图发现和分享“站在哪里、朝哪里拍、什么条件下拍”的经验。

## 三个核心价值

- **说得具体**：指出画面依据，告诉用户下一步能做什么。
- **改得明白**：区分“原图可修”和“需要重拍”，只对已实现的处理提供一键预览。
- **去得有据**：点位 = 样张 + 站位 + 方向 + 条件 + 来源。

## 核心用户与场景

普通拍照者、旅行记录者、城市漫步者、轻量内容创作者。典型场景：人像、风景、建筑、街拍、美食。产品不把用户默认当专业摄影师。

## 主线旅程

1. 访客进入首页，理解产品，查看清楚标注的示例。
2. 注册并登录；上传一张自己的照片。
3. 选择场景与可选目标 → 确认同意后分析。
4. 查看四部分结果与“最值得先做的一件事”，切换问题标注。
5. 应用支持的修改建议，手动调整、对比、复原并导出。
6. 自愿将照片关联一个机位或新建机位；默认不公开照片和位置。
7. 在地图和社区查看发布结果；另一个用户能够收藏、点赞、评论。
8. 回到个人空间，照片、分析、编辑方案和收藏仍然存在。

## 明确排除（第一版不做）

原生移动应用、实时视频教练、手势识别、复杂人脸美化、生成式换脸、一键换背景、自动推断精确拍摄坐标、全城路线规划、私信、直播、支付、真实付费会员、复杂推荐算法。

不对人脸、身材、年龄、性别、健康、种族等作评分或推断。点评对象是照片与用户的创作意图。

## 页面与路由

| 路由 | 目的 |
|---|---|
| `/` | 首页：主张、示例、上传与地图入口、真实功能、精选机位 |
| `/studio` | 上传工作台与最近分析 |
| `/studio/[photoId]` | 图像、分析结果、编辑预览与导出 |
| `/explore` | 地图与列表联动的机位发现 |
| `/spots/[spotId]` | 机位详情、样张、站位、经验与讨论 |
| `/publish` | 分步发布机位（位置 → 照片 → 拍法 → 公开确认） |
| `/me` | 个人照片、历史、发布与收藏 |
| `/login`、`/register` | 认证 |
| `/settings` | 隐私、显示偏好、退出 |
| `/privacy`、`/about` | 数据使用说明、产品介绍 |
