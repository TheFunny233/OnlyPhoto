# 已知限制与未验证项

## 功能范围

- 编辑仅实现：裁切、曝光、对比度、饱和度、暖冷倾向，以及复原/对比/保存方案/导出。**不含**拉直透视、去路人、磨皮等；这些只以文字建议形式出现，不提供“可点击却不工作”的按钮。
- 暖冷滑块是本站近似效果，不宣称专业 RAW 白平衡；不承诺恢复已丢失的高光/阴影细节。
- 社区为一级评论；无私信、直播、关注、复杂推荐。
- 不提供地图地理编码；位置由地图点选或经纬度输入。
- HEIC/HEIF 不支持，上传时明确提示。

## 平台与环境

- **仅在 Windows 11 上实际验证**；`scripts/bootstrap.sh`（macOS/Linux）已提供但**未在本机执行**。
- 未安装 `git`，本项目未进行任何提交/推送（按要求）。
- 依赖安装使用 npmmirror 镜像加速；锁文件锁定具体版本。

## 外部服务

- 真实 AI 仅在本地使用用户提供的接口完成验证；模型行为存在固有变化，抽检结论基于结构、相关性与错误边界，非逐句匹配。
- 真实地图使用 OSM 标准瓦片，仅限本地/低流量演示；无商业 SLA，不适合高并发生产。
- 供应商计费金额未从控制台获取，报告中记为“未取得费用数据/未提供”；`live_budget` 仅为请求次数预算。

## 数据与安全

- 本地 SQLite + 磁盘上传适用于单实例；多实例/高并发需更换数据库与对象存储。
- 未做正式渗透测试；已实现的边界包括：路径遍历防护、内容类型伪装拒绝、所有权校验、Origin 校验、口令 scrypt 哈希、Secure Cookie、限流。这些不构成安全保证。

## 真实模式注意

- 适配的供应商为 OpenAI 兼容 Chat Completions。若使用 Responses 等原生协议，需新增适配器并测试。
- 推理型视觉模型建议 `AI_DISABLE_THINKING=true` 与更长超时，否则可能超时。

## 未做的 P1

- 同场景前后对比的改进点比较、点位经验 AI 摘要、摄影挑战、收藏夹、多图点位、更多编辑参数、分享指导卡、PWA 安装提示、额外地图适配、容器化、`scripts/auto-iterate.mjs` 续跑器。

## 关于“公开生产上线”

本交付**未**公开部署、**未**开通付费服务、**未**推送仓库。不把本地单实例跑通表述为“已承载大规模用户”或“用户满意度提高”。
