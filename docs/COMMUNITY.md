# 社区功能说明

本轮把 PhotoMaster 的点位从“地图上的标记”继续做成一个可互动的社区。以下为当前已实现能力、设计取舍与后续方向。

## 已实现功能

### 发现与搜索
- **关键词搜索**：标题、城市、区域、描述、题材、站位说明。
- **按作者搜索**：昵称模糊匹配。
- **筛选**：城市、题材、仅看我的收藏。
- **排序**：最新发布 / 最热 / 讨论最多。
- **离我最近**：浏览器定位后按球面距离（Haversine）排序，卡片显示距离（km）。
- **分页**：每页 24 条，`加载更多`；响应返回 `total` 与 `hasMore`。
- **信息密度**：卡片显示点赞、收藏、评论、浏览量。

### 互动
- **点赞 / 收藏机位**：乐观更新 + 失败回滚，唯一约束防重复。
- **评论**：一级评论 + **二级回复**（回复挂在父评论下，按时间正序）。
- **评论点赞**：独立计数，可取消，唯一约束防重复。
- **删除自己的评论**、**举报**机位或评论。
- **关注作者**：机位页与用户主页均可关注/取消。

### 用户与推荐
- **用户主页 `/u/{userId}`**：机位列表、获赞、获收藏、粉丝、关注数。
- **猜你喜欢**：首页、发现页、机位详情页展示。
- **浏览量**：机位详情按访问者去重计数（登录用户按用户 ID，访客按 IP）。

## 设计取舍

### 热度公式
```
hotScore = 点赞×3 + 收藏×4 + 评论×2 + 浏览量×1
```
互动权重高于被动浏览，避免“只看不互动”的内容霸榜。

### 推荐策略（猜你喜欢）
1. 取热度池（最多 200 条）。
2. 登录用户：统计其点赞/收藏/评论过的机位的**题材、城市、作者**偏好，对候选加权（题材 ×6、城市 ×4、作者 ×3），并**排除已互动机位**。
3. **多样性约束**：同一作者最多 2 条、同一城市最多 3 条。
4. **兜底**：结果不足时用热度补齐；极端情况下（全新站点/已互动全部内容）回退到最热内容，保证区块不为空。

### 浏览量去重
使用 `spot_views(spot_id, viewer_key)` 唯一键，避免刷新灌水；不记录原始 IP，仅存用于去重的键。

### 与地图坐标的关系
数据库统一 **WGS84**。切到高德（GCJ-02）时，前端渲染与点选分别做正向/反向转换（`app/geo.py`、`app/static/js/coord.js`），**入库始终为 WGS84**，因此切换底图不会造成点位漂移，也不会污染数据。

## 数据模型变更（`migrations/0002_community.sql`）

| 变更 | 说明 |
|---|---|
| `comment_likes(user_id, comment_id)` | 评论点赞，联合主键去重 |
| `follows(follower_id, followee_id)` | 关注关系，联合主键去重 |
| `spot_views(spot_id, viewer_key)` | 去重浏览记录 |
| `comments.parent_id` | 二级回复（SQLite 无 `ADD COLUMN IF NOT EXISTS`，由 `app/db.py` 的 `_ensure_columns` 幂等补齐） |

迁移全部幂等，可在既有数据库上直接执行。

## 新增 / 变更 API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/spots` | 新增 `author`、`sort`(latest/hot/commented)、`near`+`lat`+`lng`、`offset`/`limit`；返回 `{spots,total,hasMore,cities}` |
| POST | `/api/spots/{id}/view` | 去重浏览计数，返回 `{views}` |
| POST | `/api/comments/{id}/like` | 评论点赞切换，返回 `{liked,count}` |
| POST | `/api/spots/{id}/comments` | 新增 `parentId`（二级回复） |
| GET | `/api/spots/{id}/comments` | 返回树形结构：一级评论含 `replies`，每条含 `likeCount`/`likedByViewer` |
| GET | `/api/users/{id}` | 用户资料与统计 |
| POST | `/api/users/{id}/follow` | 关注/取消，返回 `{following,followers}` |
| GET | `/api/recommendations` | 猜你喜欢（支持 `limit`、`exclude`） |

## 页面变化
- 首页：新增「猜你喜欢」区块。
- 发现页：筛选与排序增强、结果总数、加载更多、卡片互动数据、猜你喜欢；移动端地图/列表切换保持。
- 机位详情：作者链接与关注按钮、浏览量/互动统计、评论树（回复 + 评论点赞）、猜你喜欢。
- 新增用户主页 `/u/{userId}`。
